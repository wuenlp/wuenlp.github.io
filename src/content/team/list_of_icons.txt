========================================================================
ICONS FOR "IMPORTANT FACTS" CARDS  (and social header)
========================================================================

The `icon:` field on an importantFacts entry accepts ANY Google
"Material Symbols" icon name. The site loads the "Material Symbols
Outlined" font, so every icon in that set is available — thousands of
them.

Browse / search the full set here:
    https://fonts.google.com/icons
    (in the panel on the right, set "Material Symbols" + style "Outlined")

How to use one:
    Take the icon's name, lower_case_with_underscores, and put it in the
    `icon:` field, e.g.

        importantFacts:
          - label: "Sports"
            value: "Squash, swimming"
            icon: "exercise"

If you leave `icon` out, the card falls back to "auto_awesome".
If you type a name that doesn't exist, the card shows the raw text
instead of a glyph — so copy the name exactly from the gallery.
